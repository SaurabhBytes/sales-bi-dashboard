# Sales BI Dashboard

A full-stack Business Intelligence dashboard built with **Java, Spring Boot, Spring Data JPA, H2 Database, JavaScript and Chart.js** to analyse sales performance across regions, products and time periods.

## Features

- **Sales KPI Cards:** Displays total sales, total revenue, average revenue and top-selling product.
- **Regional Analysis:** Visualises revenue across North, South, East and West regions.
- **Monthly Revenue Trends:** Tracks revenue performance month by month.
- **Product Performance:** Compares revenue generated by different products.
- **Interactive Region Filter:** Dynamically updates dashboard metrics, charts and business insights based on the selected region.
- **Business Insights:** Displays key observations based on the selected sales data.
- **REST API Integration:** Fetches sales data from Spring Boot REST endpoints.
- **Automated Testing:** Includes JUnit tests for repository queries and application context loading.

## Dashboard Metrics

The dashboard provides the following metrics:

1. Total Sales
2. Total Revenue
3. Average Revenue
4. Top-Selling Product

## Dataset

The project uses a dataset containing **5,000 synthetic sales records**.

The dataset includes:
- Order date
- Region
- Product
- Category
- Quantity
- Unit price

**Note:** The dataset is synthetic and intended for demonstration and portfolio purposes. It does not represent actual business transactions.

## Running the Project Locally

### Prerequisites

- Java 21
- Git

### 1. Clone the repository

```bash
git clone https://github.com/SaurabhBytes/sales-bi-dashboard.git
cd sales-bi-dashboard
```

### 2. Run the application

On macOS/Linux:

```bash
./mvnw spring-boot:run
```

On Windows:

```bash
mvnw.cmd spring-boot:run
```

### 3. Open the dashboard

Visit:

```text
http://localhost:8080
```

## Running Tests

Execute the automated tests using:

```bash
./mvnw test
```

The project includes tests for:
- Total revenue calculation
- Sales retrieval by region
- Revenue aggregation by region
- Monthly revenue aggregation
- Product revenue ranking
- Application context loading
